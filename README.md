# 🤖 Klik — Локальный голосовой ассистент-аниме-тян

[![Python](https://img.shields.io/badge/Python-3.12+-blue.svg)](https://www.python.org/)
[![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey.svg)]()
[![License](https://img.shields.io/badge/License-MIT-green.svg)]()

**Klik (Клик)** — это полностью кастомный, локальный голосовой ассистент для Windows. 
Она не просто выполняет команды, а общается голосом, имеет характер аниме-тян, умеет перебивать, продолжать диалог без повторного обращения и искать музыку на разных площадках.

Главная фишка: **распознавание речи и озвучка работают локально** (на твоей видеокарте), без облаков и телеметрии.

---

## ✨ Основные возможности

*   **🎙️ Локальный слух (STT):** Использует `GigaAM-v3` — распознавание работает на видеокарте через Vulkan. Интернет не нужен.
*   **🗣️ Живой голос (TTS):** `Silero TTS` говорит голосом Ксении. Читает цифры словами (150 → сто пятьдесят) и транслитерирует английский (Google → Гугл).
*   **🧠 Тройная защита (LLM Fallback):**
    1.  Основной провайдер (Cloudflare / Gemini / Groq).
    2.  Резерв №1: **GigaChat (Сбер)** (365 млн бесплатных токенов).
    3.  Резерв №2: **OmniRoute** (работает без ключей).
*   **✋ Перебивание (Barge-in):** Начни говорить во время её ответа — она моментально замолчит и начнёт слушать.
*   **💬 Непрерывный диалог (Follow-up):** После ответа можно задать уточняющий вопрос 12 секунд без повторного «Клик». Скажи «Пока» — и она отключится.
*   **🎵 Управление музыкой:** Ищет и включает точные треки на YouTube, Яндекс.Музыке и Spotify. Управляет громкостью и паузами.
*   **📂 Плейлисты:** Умеет запоминать ссылку на твой плейлист и добавлять в него треки по команде.
*   **🎭 Аниме-характер:** Милая, эмоциональная, немного игривая (говорит «ня», «хи-хи», но по делу).

## 🛠️ Стек технологий

*   **Язык:** Python 3.12+
*   **Нейросети:** `transcribe-cpp` (GigaAM), `torch` + `silero-models`, `num2words`
*   **Интерфейс:** `tkinter` (GUI), `pystray` (иконка в трее)
*   **Управление Windows:** `keyboard`, `win32api`, `winsdk`, `pygetwindow`
*   **Звук:** `sounddevice`, `just_playback`, `soundfile`
*   **Поиск музыки:** `youtube-search-python`

## 🚀 Установка и запуск

### Вариант 1: Готовый архив (для обычных пользователей)

1.  Скачай архив `Klik.zip` (~500 мб) из раздела **[Releases](../../releases)**.
2.  Распакуй архив в папку **без кириллицы** в пути (например, `C:\Program Files\Klik` или `D:\AI\Klik`).
3.  Запусти `Klik.exe`.
4.  При первом запуске введи API-ключ (рекомендуется **Cloudflare Workers AI**, так как он работает из РФ без VPN).
5.  Скажи **«Клик»** и дай команду!

> ⚠️ **Внимание:** Путь с русскими буквами (например, `C:\Users\Иван\Desktop\Ассистент`) сломает загрузку локальных моделей.
